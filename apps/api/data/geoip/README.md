# GeoIP Database

Télécharger les bases MaxMind GeoLite2 (gratuites sur inscription) :
1. Créer un compte sur https://www.maxmind.com
2. Télécharger `GeoLite2-City.mmdb` et `GeoLite2-ASN.mmdb`
3. Placer les fichiers `.mmdb` dans ce répertoire

Sans GeoIP, le système utilise l'API ip-api.com (fallback gratuit, 45 req/min).
